# KathaQuest - AI Asset Generation Prompts

Curated visual prompts for generating kid-friendly 2D vector / storybook illustrations.

## Art Style Guidelines
- **Visual Aesthetic:** Children's storybook, warm watercolor and clean vector lines, Pixar/Ghibli inspired, vibrant warm Indian palette (mango, teal, saffron, sunshine yellow), joyful expressions, friendly rounded proportions, non-violent.
- **Aspect Ratio:** 16:9 for scenic backgrounds; 1:1 for characters and icons.
